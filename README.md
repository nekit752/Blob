# Блоб-Скейт — сборка под Android

## Что тут лежит

```
blob_skate/
├── main.py                 — код игры (адаптирован под Android, см. ниже)
├── buildozer.spec          — настройки сборки APK
├── fonts/DejaVuSans-Bold.ttf — шрифт с кириллицей (нужен внутри APK)
├── fonts/LICENSE.txt       — его лицензия (можно свободно распространять)
├── audio/*.wav             — вся музыка и звуки уже посчитаны заранее
└── .github/workflows/build.yml — сборка APK в облаке (GitHub Actions)
```

Игра по-прежнему работает и на компьютере: `pip install pygame && python main.py`.

## Что изменено под Android

- **Управление пальцем**: держите экран — прыжок (дольше держите — выше прыжок), педали в нижних углах — газ/тормоз. Клавиатурное управление (стрелки/пробел) осталось для ПК и работает как раньше.
- Кнопка «Назад» на телефоне ставит игру на паузу (и работает как «назад» в меню/паузе).
- Игра сама ставится на паузу, если её свернуть.
- Экран всегда полноэкранный и растягивается под любой телефон без искажений (1280×720 масштабируется).
- Музыка и звуки — уже готовые WAV-файлы в `audio/`, а не считаются на телефоне заново (это могло бы занять много секунд на слабом устройстве). Шрифт с кириллицей зашит в `fonts/` — системный шрифт Android для этого не подходит.
- Если на конкретном телефоне звук не заводится в «идеальном» формате — код сам пробует более простые варианты, вместо того чтобы остаться совсем без звука.

## ⚠️ Про сам файл .apk

Я не могу собрать сам `.apk` прямо здесь: в этой песочнице нет интернета и нет Android SDK/NDK/Java — а первая сборка через Buildozer скачивает несколько **гигабайт** инструментов и компилирует Python под ARM с нуля (это нормально занимает 15–40 минут даже на обычном компьютере). Поэтому ниже — два способа получить APK самому. Первый проще.

---

## Способ 1 — через GitHub Actions (ничего не ставить на свой компьютер)

1. Зайдите на [github.com](https://github.com), создайте новый **пустой** репозиторий (без README/gitignore).
2. Загрузите в него **содержимое** этой папки `blob_skate/` целиком, включая скрытую папку `.github/` (при загрузке через сайт GitHub `.github` можно перетащить вместе с остальным — она не должна потеряться; если сомневаетесь, используйте `git`, см. команды ниже).
3. Откройте вкладку **Actions** в репозитории — сборка запустится автоматически (или нажмите «Run workflow», если не началась сама).
4. Подождите 15–40 минут (первая сборка самая долгая — потом дольше 5 минут не занимает, если кэш GitHub не очистится).
5. Когда сборка позеленеет — откройте её и внизу страницы будет **Artifacts → blob-skate-apk**. Скачайте, внутри — готовый `.apk`.

Через `git` (если умеете пользоваться терминалом):
```bash
cd blob_skate
git init
git add .
git commit -m "Blob Skate for Android"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/blob-skate.git
git push -u origin main
```

## Способ 2 — локально (Linux или WSL на Windows)

Buildozer работает только на Linux/macOS (на Windows — через WSL).

```bash
sudo apt update
sudo apt install -y python3-pip python3-venv build-essential git zip unzip \
    openjdk-17-jdk autoconf libtool pkg-config zlib1g-dev cmake \
    libffi-dev libssl-dev

python3 -m venv venv && source venv/bin/activate
pip install buildozer cython

cd blob_skate
buildozer android debug
```

Готовый файл появится в `blob_skate/bin/*.apk`. Первая сборка тоже качает SDK/NDK сама (несколько гигабайт) — дайте ей время и не прерывайте.

## Установка APK на телефон

APK без подписи Google Play нужно разрешить вручную: при установке Android спросит про «неизвестный источник» — согласитесь. Файл можно просто переслать на телефон (почта, облако, кабель) и открыть.

## Если сборка не удалась

python-for-android иногда ломается на самом свежем `master` из-за внешних изменений (например, новых версий инструментов). Если сборка упала с ошибкой:
- сначала просто попробуйте ещё раз (иногда падает GitHub/сеть, а не сама сборка);
- в `buildozer.spec` замените `p4a.branch = master` на `p4a.branch = develop` — иногда наоборот стабильнее, если `master` временно сломан;
- почитайте текст ошибки в логе — обычно там прямо написано, какого пакета/инструмента не хватает;
- issues на github.com/kivy/python-for-android — почти любая ошибка уже встречалась у кого-то ещё.

## Иконка и заставка (необязательно)

Сейчас у приложения иконка/заставка по умолчанию от Buildozer. Если хотите свои — добавьте в `blob_skate/`:
- `icon.png` — 512×512
- `presplash.png` — любой квадратный размер

и пропишите в `buildozer.spec`:
```
icon.filename = %(source.dir)s/icon.png
presplash.filename = %(source.dir)s/presplash.png
```

## Если название с кириллицей не показывается на телефоне

На некоторых старых прошивках заголовок приложения с кириллицей (`title = Блоб-Скейт` в `buildozer.spec`) может отображаться криво под иконкой (сама игра на это не влияет — она всё равно рисует свой текст сама, через зашитый шрифт). Если увидите проблему — замените `title` в `buildozer.spec` на `Blob Skate` и соберите заново.
